# Horaires de publication — Le Petit Éveillé

> Heure de Paris, audience francophone. Le timing dépend de la **plateforme**,
> pas du contenu : ce planning s'applique donc à **chaque vidéo**.
> ⚠️ Tes propres stats de compte priment toujours sur ces moyennes.

## Meilleurs créneaux par plateforme

| Plateforme | Créneau idéal | Fenêtre large | Meilleurs jours |
|---|---|---|---|
| **TikTok** | **20h00** | 18h–22h | mar, mer, jeu |
| **Instagram Reels** | **18h30** | 12h–13h ou 18h–21h | mer, jeu |
| **YouTube Shorts** | **13h30** (pour le pic 15h–17h) | 12h–14h / 17h–19h | mer, jeu, ven |
| **Facebook** | **12h30** | 12h–15h | mer, jeu, ven |

**Jour le plus performant tous réseaux : le mercredi.**

## Planning type pour UNE vidéo (même jour, ex. un mercredi)

Les audiences se recoupent peu d'une plateforme à l'autre : publier le même
jour sur chaque réseau, à son heure optimale, ne se cannibalise pas.

```
12h30  Facebook        (lien article en commentaire épinglé)
13h30  YouTube Shorts  (indexé avant le pic 15h–17h ; lien en description)
18h30  Instagram Reels (lien en bio)
20h00  TikTok          (lien en bio)
```

## Notes

- TikTok : 20h marche quasi tous les jours ; c'est le créneau le plus stable.
- YouTube Shorts : publier vers 13h–14h laisse l'algorithme indexer avant que
  l'audience arrive (sortie de travail/école).
- Facebook / Instagram feed : la mi-journée (12h–13h) performe le mieux ;
  les Reels préfèrent la soirée (divertissement après le travail).
- Éviter tôt le matin et très tard la nuit (faible reach).
