# Cheat-sheet : concept → effet

Pour écrire un script vite : tu repères le concept dont tu parles, tu copies la
ligne (accent + fx + icon + transition). Le SFX se déclenche tout seul via le fx.

## Rappels de rythme (anti-diaporama)

- **Varier la `position`** plan par plan (left analyse / right preuve / center conclusion).
- **Varier la `pose`** : `point think open cross shrug wave lean`.
- **Cadence** : 2 à 3,5s par plan. Hook = plan 1 court + `punch-head` + `flash_reverse`.
- **1 accent dominant** par vidéo (la palette change la teinte de toute la scène).
- L'`icon` est ponctuel : la poser sur le plan où tu nommes le concept clé.
